<h3 align="center">Answers you can check.</h3>

<p align="center">
Zearch is a research engine that verifies its answers. It searches the web, uses TypeSafe AI's Jev evidence model to pick the passages that matter, and checks every paragraph against the sources it cites before you see it. When the evidence isn't there, it says so.
</p>

**How an answer is made:** search → Jev selects passages → a writer drafts → Jev verifies each paragraph. Anything unsupported is cut; if nothing survives, you get the source passage itself.
